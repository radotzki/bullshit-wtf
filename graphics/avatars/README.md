# Seat pictures 9 to 12

`game/src/assets/avatar8.png` to `avatar11.png` (a chick, a penguin, a fox and a koala) are drawn from
these SVG files, at 250 x 250 with a clear background, in the style of the first eight pictures: black
outlines, big round eyes, flat colours. They arrived with the 12-seat game (seats 9 to 12).

To change one: edit its SVG, open it in a browser at 250 x 250 and save a PNG with a transparent
background over the file of the same number in `game/src/assets/`.
